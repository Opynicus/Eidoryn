# GPUI 工作区

原生界面参照提供的 HTML 原型组织为三个视图：

- **控制台**：画面输出、运行/暂停、重置、音量、CRT，以及当前会话和双槽记忆卡。选择 BIOS 和打开光盘位于页面顶部；打开 EXE、快速启动和内置演示位于当前会话卡片。
- **调试器**：实时指令流、完整 CPU 寄存器、GPU 状态、单步及执行切片。左侧导航切换页面。
- **游戏视图**：保留 4:3 游戏画面和常用控制；F6 切换并返回原工作区，F11 切换全屏，Esc 退出全屏或游戏视图。

图形与外观使用右侧设置面板；点击遮罩、关闭按钮或按 Esc 收起。面板打开时不向游戏发送键盘手柄输入。F8 打开图形设置；主题页提供内置主题色板和 JSON 插件导入。默认桌面配色为 Midnight，启动参数仍可覆盖。

运行徽标由 `Snapshot::execution_state()` 决定：运行、暂停、停止与通知分开。加载失败、设置失败等通知不会自动代表停止；当前 Worker 在渲染器切换失败时会暂停，因此显示“已暂停”并保留错误说明。机器或渲染器执行故障、已确认关闭才显示“已停止”。

渲染器设置请求使用完成序号确认；请求之前留下的旧通知不会被当成当前切换结果，也不会因此提前结束等待或漏存成功切换的后端。

## 界面语言

目前提供 English（`en`）和简体中文（`zh-CN`）。在图形与外观的外观主题页选择语言，界面立即切换，并保存到用户配置目录。也可以通过 `--language en` 或 `--language zh-CN` 指定本次启动语言。

启动优先级为：命令行参数、已保存偏好、系统 `LC_ALL` / `LC_MESSAGES` / `LANG`（首个非空值）。中文系统语言选择简体中文，其余语言回退英文。无效或不可读的偏好也回退到系统语言。

词条集中在 `src/i18n.rs`，每个键必须同时提供两种语言，编译时生成完整查找。游戏标题、主题插件名称、寄存器标识和底层技术错误保留原始内容；当前没有将命令行帮助和核心诊断全文翻译。

## 用户设置

界面操作会保存语言、主题、导入主题文件路径、CRT、音量、静音状态、成功切换后的首选渲染器以及纯画面全屏偏好。拖动音量时只更新播放音量，松开滑条后保存。设置写入临时文件，完整写入后替换旧文件；保存失败会显示通知。

配置文件为 Linux 的 `$XDG_CONFIG_HOME/eidoryn/settings.json`（未配置时为 `~/.config/eidoryn/settings.json`）、macOS 的 `~/Library/Application Support/eidoryn/settings.json`、Windows 的 `%APPDATA%/eidoryn/settings.json`。缺失字段使用默认值；无效文件显示通知并恢复默认设置。

`--language`、`--theme`、`--theme-plugin`、`--crt`、`--volume 0..100`、`--mute` / `--unmute`、`--renderer`、`--clean-fullscreen` / `--fullscreen-controls` 优先于已保存设置。启动参数不会自动写回配置，只有界面修改的相应选项才会保存。无窗口运行不读取桌面设置。

已保存的主题不可用时回退 Midnight；已保存的渲染器不可用时回退串行软件渲染，并显示通知。明确通过命令行请求不可用的主题或渲染器仍会返回错误。

## 键盘与显示

- Tab / Shift+Tab 移动焦点，Enter / Space 激活控件；聚焦控件后也可用方向键移动焦点。设置抽屉内循环焦点，不进入背景控件。
- 音量滑条聚焦时，方向键以 5% 调整，Home / End 设置为 0% / 100%。Esc 收起设置或将焦点交还游戏；鼠标点击操作结束后也恢复游戏输入。
- 侧栏、按钮、主题选择与设置开关提供焦点样式，图标按钮与窄侧栏提供悬停说明。这是键盘支持的第一步，尚未实现完整的辅助技术语义。
- 图形设置中的“纯画面全屏”隐藏顶部标题和底部控制栏，F12 切换此偏好，F11 / Esc 仍可退出全屏。F8 仍能打开设置。

窗口较窄时收起导航文字，并将会话和记忆卡放到画面下方；内容区可滚动。抽屉以 `25rem` 为宽度并限制在窗口宽度内，以适应字体缩放。GBA 和 PS2 仅为标注“未支持”的展示项，没有平台切换行为。界面中的状态来自模拟器快照，不使用原型示例数值。

图标由原型中的 SVG 形状生成并编译到程序中，不依赖启动目录。游戏图像继续复用原有显示与 CRT 路径。

## 验证

```bash
cargo test --locked --features ui-tests --bin eidoryn desktop::tests
cargo test --locked --no-default-features --features desktop --bin eidoryn desktop::settings::tests
```

`ui-tests` 只启用 GPUI 的测试支持。测试覆盖侧栏点击、键盘激活、设置焦点隔离、语言与主题保存、纯画面全屏切换，以及两种语言、四套主题、不同窗口尺寸下的布局渲染，包含 640×480 与 20px 根字号的压力场景；应用通常仍请求至少 980×680 的窗口。无 Vulkan 构建另测首选渲染器回退。测试平台不等于实际显示器的视觉验收。

README 的中英文截图来自 Linux Wayland、150% 显示缩放下的原生窗口，内容为内置原创演示。相同环境另行检查了纯画面全屏；Windows/macOS 的高 DPI 和辅助技术支持仍需实机验证。

字体请求复用与侧栏缓存的实现、内存测量口径和前后对比见 [UI 内存测量](UI-MEMORY.md)。视频更新复用侧栏；主题、语言、导航状态和尺寸变化仍会正确刷新。
