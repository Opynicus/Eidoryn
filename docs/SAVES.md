# 记忆卡

Eidoryn 启动游戏时默认连接两张 128 KiB 记忆卡：当前工作目录下的 `saves/card1.mcd`、`saves/card2.mcd`。不存在时创建已格式化的新卡，已有文件按原始字节读取。可以在其他支持原始 PS1 卡格式的工具中使用；不支持带额外头部的卡容器。

```bash
./target/release/eidoryn --bios /path/to/bios.bin --disc /path/to/game.cue \
  --card1 saves/game.mcd --card2 saves/shared.mcd --run
```

请使用游戏里的存档点或存档菜单。记忆卡不是运行状态快照，关闭窗口不会自动把角色当前位置存入游戏。界面 `Saved` 表示当前记忆卡数据已同步到文件，不代表游戏已创建了存档。

游戏通过 SIO 写完有效扇区后，工作线程每 250 ms 批量落盘。暂停、重置、切换媒体、正常关闭及 **Flush saves** 会立即同步。Reset 恢复机器运行状态，但保留最新卡内容。游戏自身跨多个扇区的保存过程仍需要正常完成。

`--card1 PATH`、`--card2 PATH` 可分别选择两张卡；未指定的槽仍用默认卡。`--no-memory-cards` 断开两个卡槽，不能与自定义卡参数一起使用。无窗口运行也采用相同规则；纯检查/导出命令不打开记忆卡。

持久化先写同目录临时文件，刷新文件后原子替换卡文件，并在 Unix 刷新父目录。错误大小的文件会报错，不会自动格式化或覆盖。每张卡使用独立的旁路锁文件，防止两个模拟器实例同时写同一张卡；正常退出会释放锁，留下 `.lock` 文件不表示仍被占用。启动多个实例时请指定不同卡文件。

写盘失败时模拟暂停，保留内存里的新数据并显示路径与错误；修复目录权限/磁盘空间后点击 **Flush saves** 重试。失败时不会把脏数据标为已保存，也不会允许普通关闭请求直接丢弃它。强制结束进程仍可能失去尚未同步的部分。

测试覆盖两个槽的串口读写、校验和、ACK、断开的事务、重置保留、原子写入失败与重试、同一卡并发锁、重新打开后的字节一致性。这些协议测试不代表所有游戏的存档兼容性均已验证。
