# PS1 release metadata and cover validation

Verified on 2026-11-20 with Rust 1.100.0, CachyOS Linux x86-64 and an AMD Ryzen 9 8945H. Database and image tests use temporary directories.

## Offline snapshot

The bundled snapshot `Wikidata/PS1/2026-11-20` contains 302 distinct PS1 product IDs. It covers 202 Japanese, 60 European and 40 US entries. There are 93 complete regional dates, one month-precision date and one year-precision date. The other 207 edition dates remain unknown. A separate work-level date is available for 66 entries.

The generator requires PS1 as a platform on the work, then checks the platform on the serial statement or accepts one of seven reviewed PS1 product IDs for Crash Bandicoot, Ridge Racer and Super Hero Operations. Serial prefixes select the supported territories. SCPS-45xxx Asian releases are omitted. A regional date must match the territory and the PS1 platform qualifier, with a reviewed exception for the original Crash Bandicoot. Several IDs in a territory suppress the inferred edition date. The work-level field uses the sole unqualified first-publication statement on a work with PS1 as its only recorded platform. Each edition keeps its Wikidata item/serial key. Structured data and labels are available under CC0. [PlayStation ID](https://www.wikidata.org/wiki/Property:P2606) · [Publication date](https://www.wikidata.org/wiki/Property:P577) · [Wikidata licensing](https://www.wikidata.org/wiki/Wikidata:Licensing)

Run `python3 scripts/build_library_catalog.py` to query the current source. For a dated rebuild, supply the three raw query responses using `--records`, `--japanese` and `--first-dates`. The reviewed snapshot regenerated byte-for-byte from its responses. SHA-256 of the shipped TSV is `8f02360faae9615481204fb6a73109101b0d4fc412097b697c49a48a2255738e`.

## Matching results

The ten-case acceptance sample produced six exact matches, two cases requiring confirmation, two misses and zero incorrect automatic assignments. The six matches cover US/Japanese Crash Bandicoot, US/Japanese Ridge Racer, European Lucky Luke (`1998-04`) and Japanese Super Hero Operations (`1999`). The confirmation cases use a conflicting disc region and a filename-only title. The misses use US Tekken 3 and an unidentified homebrew title. The year-only work publication for Bear in the Big Blue House also leaves its US edition date unknown. A temporary-database restart test verified that title, region, date and a manually chosen edition survive refresh; restoring the automatic date leaves the other edits in place.

A second check read six locally supplied images through the actual PS1 probe. They represent five distinct serials. One image matched, five missed, none required confirmation and none matched incorrectly. These two selected samples have different purposes and do not estimate full-library accuracy.

## On-demand refresh

**Fetch from Wikidata** queries the current release by disc serial. Successful responses and ambiguous candidates are stored in the user's SQLite library. Tests cover reopening the library offline, a slow response arriving after a newer request, a manual correction during a lookup, and preserving existing data on a miss or network failure. A live query for the US Crash Bandicoot serial returned its title and release date of 1996-09-09.

## Covers

Import immediately indexes the disc offline. By default a committed new game also queues a background lookup for its release and cover. Hot rescans and verified copies do not enqueue work. **Refresh library data** reads all visible game IDs from SQLite, including games outside a search, and revalidates artwork and release data. Three workers share a batch. Games with the same serial share a metadata lookup. A failed cover refresh leaves the last valid image available. **Get cover** requests an individual cover and **Fetch missing covers while browsing the library** can backfill older entries. The library settings allow both automatic operations to be turned off for offline use. The first Libretro lookup downloads the upstream PS1 Redump DAT and indexes playlist names by serial and region in the user's SQLite database. The index is refreshed on demand after 30 days. A unique matching playlist name identifies the regional front cover in Libretro's official PlayStation thumbnail repository. [Libretro catalog](https://github.com/libretro/libretro-database/tree/master/metadat/redump) · [Libretro thumbnails](https://github.com/libretro-thumbnails/Sony_-_PlayStation)

ScreenScraper uses the PS1 serial and regional front-cover media. It requires developer credentials and the account may need authorization for serial-only requests. IGDB uses a catalog title, an exact PS1 match and an explicitly regional cover. It requires a client ID and access token. The custom HTTPS template accepts a serial placeholder and supports existing PSX Covers settings. [ScreenScraper API](https://www.screenscraper.fr/webapi2.php) · [IGDB API](https://api-docs.igdb.com/) · [PSX Covers downloader](https://github.com/xlenore/psx-covers/blob/main/README.md)

Tests verified regional and ambiguous matches, JPEG and PNG decoding, atomic replacement, manual cover precedence, offline thumbnail recovery, cancellation, response limits, negative caching and host-wide backoff. Live Libretro validation downloaded the catalog and a PNG into a temporary user library, then checked the original and its generated thumbnail. ScreenScraper and IGDB were tested with synthetic responses. Live validation for those two services requires credentials. The live batch test ran a full refresh, an incremental lookup and a second full refresh against Wikidata and Libretro. It verified cache reuse during the incremental lookup, replacement of the old downloaded file during full refresh, and preservation of the user's title.

```sh
cargo test --locked --lib --all-features library::metadata::
cargo test --locked --lib --all-features library::covers::
cargo test --locked --lib --all-features local_ps1_image_sample -- --ignored --nocapture

cargo test --locked --lib --all-features live_wikidata_serial_metadata -- --ignored
cargo test --locked --lib --all-features live_libretro_cover_smoke -- --ignored
cargo test --locked --lib --all-features live_psx_covers_smoke -- --ignored

```

The local disc test requires the images named in its fixture under `tests/`. The loopback test requires a local socket. The live tests require internet access and sample individual releases.
