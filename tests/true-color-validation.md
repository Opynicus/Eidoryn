# PS1 真彩色实机验证

## 验收结果

2026-11-19 在 Linux 上使用 AMD Radeon 780M 验证。下表中的实机测试均在物理显卡上运行。

| 项目 | 结果 |
| --- | --- |
| 物理 Vulkan（RADV）与 OpenGL 4.6（radeonsi） | 每个后端通过 9 项硬件集成测试。在 1×、2×、4× 下，灰色 100 和 103 的 GPUREAD 均返回 `0x318c`。原色呈现为 99、99，真彩色呈现为 100、103。 |
| 计算着色器 | 两个物理后端和 Mesa 软件适配器上的 Vulkan、OpenGL 均通过像素回归，覆盖 256 像素渐变、客体抖色、调制与 CLUT、透明纹素、四种混合、mask、回绕复制、反馈和 RGB24。 |
| 状态恢复 | Vulkan 通过运行及暂停切换、快速读档、重置和倒带测试。载入 V1 后保留已锁存的预览，重建的呈现缓冲从灰度 99 开始，重绘后恢复为 103。两个物理后端均验证切换失败后仍可使用原配置。 |
| 桌面和软件渲染 | 配置迁移、设置交互、软件模式下保留硬件偏好及工作区回归通过。 |
| DirectX 12 与 Metal | WGSL 成功转换为 HLSL 和 MSL。本次缺少 Windows 和 macOS 测试设备，尚待实机验证。 |

已执行的验收项目全部通过。

## 固定场景与帧时间

《恶魔城：月下夜想曲》美版。Alucard 位于紫色楼梯间，从同一即时存档开始，每 30 个视频场的前两场按下 Triangle，触发后撤及其残影。每种色深独立恢复三次，每次记录 128 场，无帧率限制。

| Vulkan 2×，512 × 480 输出 | 场数 | 平均帧时间 | P95 |
| --- | ---: | ---: | ---: |
| 原色 RGB555 | 384 | 10.907 ms | 12.947 ms |
| 真彩色 RGB888 | 384 | 10.886 ms | 12.965 ms |

测试设备为 AMD Ryzen 9 8945H、集成 Radeon 780M Graphics (RADV PHOENIX)，Linux 7.3.4-1-cachyos，Mesa RADV 27.0.0-devel (git-f7dd61f78f)，Vulkan 1.4.363。两个模式都使用物理 GPU、release 构建和 CPU 解释器。表中记录每次推进到下一个 VBlank 的模拟器执行时间，加上锁存帧回读。CSV、音频/RGB 哈希计算和窗口呈现均在计时范围之外。P95 取每种模式所有样本排序后的第 365 项。

## 游戏画面与客体轨迹

三轮中的配对视频场均得到相同的 PC、步数、GPU 命令数、CD 扇区数、SPU 传输量和 PCM 哈希。每轮 128 场执行 66,587 条 GPU 命令，其中 125 场的呈现图像哈希因色深改变。

最后一场中，颜色差异集中在角色和后撤残影所在的区域。512 × 480 的呈现图像中有 2,142 个像素改变，全帧颜色数从 165 增至 200。以左上角为原点，像素 (270, 224) 的 RGB 从 (57, 57, 99) 变为 (63, 65, 101)。两张图在 x=208–297、y=224–322 之外逐字节相同。

## 复现

使用对应游戏和 BIOS 建立即时存档，将路径填入以下命令。示例只读介质和存档，为每次运行新建一个输出目录。实测使用 SCPH-5501，BIOS SHA-256 为 `11052b6499e466bbf0a709b1f9cb6834a9418e66680387912451e971cf8a1fef`，即时存档 SHA-256 为 `609486bd629f8bffa1e6406827b57858487d36fca7bdc1bd660f2d13ddaabfae`，恢复时 PC 为 `00001bcc`。

```sh
cargo build --locked --release --no-default-features --features vulkan --example true_color_bench
target/release/examples/true_color_bench "$BIOS" "$DISC_CUE" "$STATE" vulkan 2x 128 1000 ./color-run
```

`1000` 是十六进制手柄按键掩码，`0000` 对应无按键。每种色深生成逐场 CSV 以及最后一场的 PPM 图像，均在 CRT 滤镜之前取样。
